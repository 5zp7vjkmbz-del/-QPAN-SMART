Hướng dẫn chỉnh sửa

  1. Tải tệp index.html về máy.
  2. Mở bằng VS Code, Notepad++ hoặc trình soạn thảo HTML để sửa chữ, màu sắc và tính năng.
  3. Muốn có link công khai: tải index.html lên GitHub, vào Settings → Pages → Deploy from a branch → main / root → Save.
  4. GitHub sẽ tạo link dạng https://ten-tai-khoan.github.io/qpan-smart/; có thể sửa tiếp trong repository.
Chỉ dùng dữ liệu giả khi trình diễn. Không nhập thông tin cá nhân nhạy cảm hoặc hồ sơ sinh viên thật vào bản demo công khai.
